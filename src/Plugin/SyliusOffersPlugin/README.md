## Overview

The Sylius Offers Plugin adds a complete promotional offers management system to your Sylius store. Create beautiful, targeted promotional offers with customizable designs, countdown timers, and comprehensive analytics. Perfect for displaying limited-time promotions, seasonal sales, and special deals across your store and mobile apps.

### Key Features

- 🎯 **Advanced Targeting** - Show offers based on URLs, products, categories, channels, and locales
- 🎨 **Customizable Design** - Full control over colors, badges, and button styles
- ⏱️ **Countdown Timers** - Live countdown to offer expiration with real-time updates
- 📊 **Analytics Dashboard** - Track views, clicks, and conversion rates for each offer
- 📱 **REST API** - Full API endpoints for Flutter/React Native mobile apps
- 🏷️ **Multiple Display Types** - Cards, banners, popups, and sidebar widgets
- 🔄 **Auto-tracking** - Automatic view and click tracking with conversion rate calculation
- 🌍 **Multi-channel Support** - Target specific channels and locales
- ⚡ **Cache Support** - Redis/APCu integration for optimal performance
- 🌐 **Multi-language** - English and French translations included

## Requirements

- PHP 7.4 or 8.0+
- Sylius 2.3+
- Symfony 6.0+
- Doctrine ORM 2.0+
- MySQL 5.7+ or PostgreSQL 9.6+
