# Sylius Best Seller Plugin

## Overview
The Sylius Best Seller Plugin adds functionality to track and display best-selling products based on order data. It provides admin configuration, homepage widgets, and API endpoints for mobile apps.

## Features
- ✅ Automatic tracking of product sales from completed orders
- ✅ Multiple time periods (daily, weekly, monthly, yearly, all-time)
- ✅ Configurable display settings in admin panel
- ✅ Twig components for homepage display
- ✅ REST API endpoints for Flutter/React Native apps
- ✅ Caching system for optimal performance
- ✅ Console commands for manual updates
- ✅ Multi-channel support

## Installation
